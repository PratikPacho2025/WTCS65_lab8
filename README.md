# CRICLIVE --- Live Cricket Score Management Platform

CRICLIVE is a modern real-time cricket score management platform
designed to provide a clean and professional experience for managing and
displaying cricket matches.

## Project Overview

The project provides a modern cricket-focused interface with a premium
SaaS-style design. The UI is designed around live scoring, teams and
players, REST APIs, and match intelligence.

### Main Technologies

-   Spring Boot
-   MySQL
-   REST APIs
-   HTML, CSS and JavaScript / Frontend UI
-   Responsive Web Design

## UI Features

### Home Page

-   Modern CRICLIVE navigation bar
-   Large hero section
-   Live cricket platform badge
-   Real-time cricket scoreboard preview
-   India vs Australia score display
-   Live score and platform CTA buttons
-   Feature highlights
-   Lime-green and black visual theme
-   Responsive layout

### Features Page

The features section includes:

1.  **Live Scoring**
    -   Record runs, wickets and ball-by-ball events.
    -   Display real-time scoring information.
2.  **Teams & Players**
    -   Manage teams and player information.
    -   Connect team and player information with MySQL storage.
3.  **REST APIs**
    -   Manage matches, teams, players and scoring events through REST
        endpoints.
4.  **Match Intelligence**
    -   Display batting, bowling and match statistics.
    -   Provide a clean dashboard-oriented experience.

## UI Design

The interface follows a premium sports-technology/SaaS design system:

-   White and off-white backgrounds
-   Lime-green accent color
-   Black and dark charcoal components
-   Large bold typography
-   Rounded cards and buttons
-   Subtle shadows and borders
-   Soft green gradients
-   Responsive layouts
-   Clean spacing and visual hierarchy
-   Hover and micro-interactions

## Responsive Design

The UI is designed to work across:

-   Desktop
-   Laptop
-   Tablet
-   Mobile devices

On smaller screens, the hero content and scoreboard stack vertically,
while feature cards change to a single-column layout.

## Project Goal

The goal of CRICLIVE is to provide a professional interface for live
cricket score management while keeping the experience simple, fast,
readable and visually engaging.
